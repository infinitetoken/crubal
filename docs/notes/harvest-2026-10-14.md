# Harvest: what the old Facet Library teaches the CRUBAL 2 spec

**Date:** 2026-10-14. Source: `nes4less/shell` `api/facets/` (the Facet Library behind facets.crubal.com),
read file by file. Each item is a lesson the old system learned on live data, and the spec change it
suggests. **All fifteen approved by the operator and applied to the spec on 2026-10-14**, with corpus cases
(dictionary 006–007, rules 006–008, store 008–010, dictionary-errors d09).

| # | Lesson (file) | What happened | Spec change | Chapter |
|---|---|---|---|---|
| H1 | **Itemize, don't count** (`_manifest-fungibility`) | Planet Earth's discs were stored as one component "discs" (and as `disc: 3`) when each disc held different episodes. A count is only right for identical things (two AA batteries) | A part slot says whether it is **fungible**. A fungible slot may hold a count (`battery: AA ×2`); a non-fungible slot MUST hold one part per instance. Slots are non-fungible unless they say `fungible: yes` | 5.6 |
| H2 | **Parts drift under re-derives** (`_manifest-canon`) | One DVD accumulated 27 component names for 4–6 real parts ("disc hub", "disc hub holder", "inner trays") because each pass named them afresh | Intake MUST match incoming rows and parts to existing ones before minting new row keys: by identity child, else by the fold key of a declared **match** child (`match: name`), else by review. A contract MAY propose a consolidation; it lands as a suggestion | 1.6, 9.2 |
| H3 | **Per-item notables** (`_wildcard-facet`, `_bag-pattern`) | Signed, misprint, edition number 4522, graded: facts that exist only for one unit and that no class asks for | A core compound **`notables`** (`key` text, `value` text, pick any) on every record, for facts no class asks for. A key that recurs across enough records (a package threshold, default 5) is **proposed** as a facet through review: "promotion lives in redundancy" | 1, 9.5 |
| H4 | **Candidates, not live vocabulary** (`_gatekeeper`) | New definitions landed as candidates in the same table, matched against active ones, promoted or merged by a person; "the agent advises, it does not authorize"; the mechanical baseline stays visible beside the agent's call | A facet (and class) **lifecycle**: `candidate` → `active` → `retired`. Candidates are invisible to forms, views and rules; promotion is a review decision; merging folds the key into aliases. Review items show the deterministic match beside any AI recommendation | 4.1, 9.5 |
| H5 | **Vetoes are evidence** (`_classify-consensus`) | "Media Storage / DVD Racks" positively means *not a DVD*. A veto row killed false positives that votes alone couldn't | Evidence can **veto**: an observation or intake value may say a value is *not* true (`format is not DVD`). A vetoed value can't be confirmed or win consensus. Same for proposed classes (H6) | 9.7 |
| H6 | **Classes are inferred too** (`_classify-cascade`) | The class a product belongs to came from evidence legs plus consensus, not from a person | **Proposing `wears`**: a receive contract may propose classes for a record; they land through the same consensus (≥2 independent sources, no veto) or as suggestions. Today the spec doesn't say how `wears` gets set from evidence | 5.5, 9.7 |
| H7 | **Cheap first, AI last, abstain over wrong** (`_title-cascade`) | Multi-source lookup, then a free web cross-check, then AI only on disagreement; "a wrong title is worse than none" | Conditions can test a value's **state**: `title is conflicted`, `title is confirmed`, `title is unobserved`. That lets a contract's `when` build a cascade (`run aiTitle when title is conflicted`). And: a receive contract MAY **abstain**, which is never a value | 6.3, 7.4 |
| H8 | **Agreement needs a fold** (`_title-cascade`) | Titles from different sources never matched exactly ("The Secret of NIMH (DVD)" vs "Secret of NIMH") | A facet may declare **`agree-by`**: how values compare for consensus and conflict, beyond equality (the alias fold, plus a package-named normalizer such as dropping leading articles and format words). Storage still holds one real value | 4.2, 9.3 |
| H9 | **Expected facets follow values** (`_conditional-prediction`) | `work type = series` should ask for season and episode; `edition = Criterion` for spine number | Class lines MAY carry **`when`**: the line is asked only when its condition holds (`season when workType is series`). Outside it the facet is unasked, not `-` (that's a gate's job) | 5.3 |
| H10 | **Redundant declarations hide drift** (`_delta-check`) | Authors re-declared facets a parent already declared | Publish SHOULD **warn** on a class line that restates a used facet without narrowing it | 5.10 |
| H11 | **Completeness as a measure** (`_facet-completeness`, `_reconcile`) | "26 of 27 empty" passed as complete; per-part scaffolding made box sets look less complete than single discs | A record's **completeness** is a number, 0–1: asked facets with a value ÷ asked facets, unknown counting as empty; parts are measured on themselves and never enlarge the whole's denominator | 6.9 |
| H12 | **Readable with zero CRUBAL** (`_portable`) | A payload another app could use with no CRUBAL knowledge: `{key, value, value_type}` as the floor, the rest advisory | A standard **portable shape** in the core package: each value as `{key, label, type, value}` with everything else ignorable; the default machine shape for feeds and agents | 12.1 |
| H13 | **Share by link** (`publish-write`) | An owner published a lens with some facets private and got an unguessable link; unpublishing flips a flag; republishing keeps the link | Offer's `to:` gains **`link`**: anyone holding an unguessable token; revocable; republishing keeps the token | 7.8 |
| H14 | **Fallbacks in templates** (`expression/parser`) | `{path ?? fallback}` | Settles chapter 6.11's open question: templates gain **`{a ?? b}`** (first non-empty) and **`{a?}`** (empty instead of nothing) | 6.4.1 |
| H15 | **Equality ignores provenance; identity is data** (`_reconcile`) | A fact's identity is (owner, facet), never its row id, so a merge or restamp doesn't duplicate it | Already in the spec (addresses, chapter 1.11). No change; worth a corpus case | corpus |

## Not harvested

Transports, P2P sync, the flow VM, acoustic/kernel layers, identity trust scoring, the six-layer visibility
stack (replaced by audiences and roles), and ME- or media-specific algorithms (the contained-work resolver,
the title sources, the manifest discovery prompts). The algorithms belong in a media or ME package as
contracts, now that H2, H5–H8 give them the language to be written in.
